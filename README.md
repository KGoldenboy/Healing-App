# Healing — meeting yourself

A self-observation and self-support web application, 100% local (no network, no AI).
Understand why you do what you do, and find a concrete path to change, step by step,
without judgment.

> It is not medical advice, a diagnosis, or a therapist.

**Available in three languages:**

## Build

The app is a single self-contained HTML file assembled from `app/` (HTML/CSS/JS)
and `data/` (JSON content) by `build.py`:

```bash
python3 build.py
# → dist/healing-app.html
```
